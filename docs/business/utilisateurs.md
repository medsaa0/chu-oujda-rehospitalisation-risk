# Utilisateurs de la plateforme

## 1. Direction hospitalière

La direction consulte les indicateurs globaux afin de suivre :

- le nombre d’hospitalisations ;
- le taux de réhospitalisation ;
- la durée moyenne des séjours ;
- les principales catégories de patients ;
- les tendances générales.

Dashboard principal :

- Executive Overview.

## 2. Responsable hospitalier

Le responsable hospitalier analyse :

- les admissions ;
- les réhospitalisations ;
- les durées de séjour ;
- les diagnostics ;
- les traitements ;
- les profils à risque.

Dashboards principaux :

- Hospitalization Analysis ;
- Readmission Analysis ;
- Clinical Analysis.

## 3. Médecin ou responsable clinique

Le médecin consulte les analyses cliniques agrégées afin d’identifier :

- les diagnostics fréquents ;
- les traitements utilisés ;
- les groupes de patients concernés ;
- les facteurs associés à la réhospitalisation.

La plateforme constitue un outil d’aide à l’analyse et ne remplace pas la décision médicale.

## 4. Data Analyst

Le Data Analyst utilise les Data Marts et Power BI pour :

- créer les KPIs ;
- produire les rapports ;
- analyser les tendances ;
- interpréter les résultats ;
- construire les dashboards ;
- communiquer les conclusions.

## 5. Data Engineer

Le Data Engineer est responsable de :

- l’ingestion des données ;
- la qualité des données ;
- la transformation des données ;
- l’alimentation du Data Warehouse ;
- la création des Data Marts ;
- l’automatisation des pipelines ;
- la journalisation ;
- le monitoring.

## 6. Administrateur

L’administrateur supervise :

- les accès ;
- les exécutions des pipelines ;
- les erreurs ;
- la disponibilité des données ;
- les paramètres techniques.
